# 坚果云 WebDAV 同步设置教程

> 这份教程是给「人生任务管理器」Windows 版 / 以后 Android 版用的。
> 整条链路只有一句话：**你的数据始终在本机（一堆 md 和 json 文件），坚果云只是把这些文件在设备之间搬来搬去的通道。**

---

## 一、为什么用坚果云，而不是网盘客户端

坚果云的同步客户端会把整个文件夹搬来搬去，但我们需要的是**让程序自己决定什么时候同步、怎么处理冲突**。
WebDAV 就是一个"标准的文件读写接口"，坚果云支持它，所以我们用它当运输通道：

- 程序改完文件 → 用 PUT 传上去
- 另一台设备打开程序 → 用 PROPFIND 看一眼服务器上有啥变化 → 有变化就 GET 拉下来
- 两边都改过同一个文件 → 留两份，绝不覆盖（见下面第五节）

---

## 二、生成应用密码（关键，别用登录密码）

1. 打开 <https://www.jianguoyun.com/> 并登录
2. 点右上角**账户名** → **【账户信息】**
3. 选**【安全选项】** → 找到 **第三方应用管理** → 点 **"添加应用密码"**
4. 名称随便填（建议写 `人生任务管理器`），点**生成密码**
5. 会得到一串形如 `abcd1234efgh5678` 的密码 —— **只显示一次，先复制出来**

> 手机上也能生成：iOS 客户端「设置 → 第三方应用管理」，安卓端「设置 → 第三方应用管理」。

这一步是必须的：**登录密码不能用于 WebDAV**，第三方应用一律要求用应用密码。用登录密码会得到 401。

---

## 三、填进软件里

打开「人生任务管理器」→ 左侧**设置** → **WebDAV 同步（坚果云）**：

| 字段 | 填什么 |
|---|---|
| 服务器地址 | `https://dav.jianguoyun.com/dav/` |
| 账号 | 你的**坚果云登录邮箱**（不是昵称） |
| 应用密码 | 第二步生成的那串密码 |
| 服务器上的目录 | `/LifeTaskManager`（随便起，多台设备要**填成一样**） |
| 启用同步 | 打开 |

然后**按顺序**点：

1. **测试连接** —— 看到"连接正常，/LifeTaskManager 下已有 N 个条目"就通了（第一次会自动建目录）
2. **预演同步** —— 只报告"将要上传/下载什么"，**不动任何文件**。第一次建议先看一眼
3. **立即同步** —— 真正同步。此后左侧导航栏最下面的云朵图标、托盘右键菜单里也都能触发

### 第二台设备（以后 Android / Mac）

装好软件 → 同样填上面四项（**服务器目录必须一模一样**）→ 直接点「立即同步」。
第一次会把服务器上的文件全部拉到本机，之后就是双向增量同步。

## 四、免费额度与硬限制（重要）

| 限制项 | 免费版 | 说明 |
|---|---|---|
| 请求频率 | **每 30 分钟 600 次** | 同步是"攒着一起做"的，不会改一个字传一次；平时手动同步一次通常只花几十次请求 |
| 上传流量 | 1 GB / 月 | 纯文本极其省，写满一年也到不了 |
| 下载流量 | 3 GB / 月 | 同上 |
| 单文件大小 | 500 MB | 我们全是小文本文件 |
| 单次请求条目数 | **750 个** | 一个目录里文件别超过 750；我们按月分文件夹（`杂记/202609/`），天然满足 |
| 付费版 | 1500 次 / 30 分钟 | 如果你同步很频繁可以考虑 |

出现 `HTTP 429`：说明短时间内请求太多，我们的客户端会自动退避重试；连续失败就等半小时再同步。

## 五、冲突是怎么处理的（为什么不会丢数据）

同步用的是**三态比较**：`上次同步时的状态` / `本机现在` / `服务器现在`。

| 情况 | 处理 |
|---|---|
| 只有本机改了 | 上传 |
| 只有服务器改了 | 下载，覆盖本机同名文件 |
| 两边都改了 | **两份都留**：本机版本留在原路径，服务器版本另存为 `xxx.冲突-设备名-时间.md`，然后两个文件都同步上去 |
| 本机删了、服务器没改 | 服务器上跟着删 |
| 服务器删了、本机没改 | 本机也删，但**先扔进 `回收站/`**（留 30 天，不是真删） |
| 服务器删了、本机改过 | 保住你改的那份，重新传上去 |

同步完如果看到"冲突 1"，去设置页会列出冲突文件名，**看完删掉不需要的那份就行**。

删除永远不会直接消失：本机删除 = 进 `回收站/`，30 天后才随清理消失。

## 六、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `401 Unauthorized` | 密码填成了登录密码 → 用第二节生成的应用密码；或账号填的不是邮箱 |
| `404 / 409` | 服务器目录还不存在 → 客户端会自动创建，看到这个一般是一次性的；如果反复出现，检查地址末尾是不是少了 `/dav/` |
| `412 Precondition Failed` | 上传时发现服务器上的文件被别人（另一台设备）改过了 → 属于正常的冲突保护，会转成"两份都留" |
| `429` | 请求太频繁，等一会儿；或减少手动同步次数 |
| 同步"没反应" | 看设置页的同步日志：显示"已是最新"说明真的没变化；显示扫描了 0 个目录，多半是服务器目录填错 |
| 中文文件名乱码 | 客户端已按 UTF-8 百分号编码处理；若在别的工具里看到乱码，是那个工具的编码问题，文件本身是好的 |
| 想换服务器/目录 | 设置里改完直接同步；程序会重建同步基准，不会删你的文件 |

### 安全提醒

- 应用密码存在**本机**的 `%APPDATA%\LifeTaskManager\device.json`，**不在 vault 里**，所以不会被同步上传
- 不想要了就回坚果云后台「安全选项 → 第三方应用管理」把它吊销，软件里同步就会开始报 401
- 把 vault 文件夹直接交给 Obsidian 打开是可以的（格式兼容），但**两边不要同时编辑同一个文件**，否则会产生冲突副本
